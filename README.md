# Digital-platforms-reversi

Разработка игры «Реверси» (Отелло) на базе архитектуры CdM-16 в среде Logisim. Курсовой проект по дисциплине «Цифровые платформы».

## Состав проекта
* `reversi.circ` — основная схема игры в Logisim.
* `cdm16.circ` — модель процессора CdM-16.
* `*.jar` — необходимые библиотеки для работы симулятора и отладки.
* `Документация` — ТЗ, пояснительная записка и презентация проекта в форматах .docx и .pptx.

## Как запустить
1. Убедитесь, что у вас установлен Logisim с поддержкой внешних библиотек.
2. Подключите JAR-файлы из корневой директории в качестве библиотек в Logisim.
3. Откройте файл `reversi.circ`.
4. Запустите тактовую частоту (Simulation -> Ticks Enabled).
